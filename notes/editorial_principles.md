# 选编原则（Editorial Principles）

本选本不是旧书重印，而是一次**以文史脉络重构**的专题编选。以下原则统摄选目、分辑、注释与编排。

---

## 一、根本判断：黄裳游记 = 「地点触发的文史随笔」

黄裳写一地，往往由眼前风景/旧迹切入，旋即转入掌故、史事、书籍、戏曲与人物，落点常在**历史兴亡之感**。因此：

- **不以「到此一游」式风景文为标准**，而以「能否打开一段文史」为取舍。
- 同一地点的不同时期书写（如鸡鸣寺1946/1979）视为**结构资源**，刻意并置以显时间纵深。
- 「读书即旅行，访书即考古」是其独特面向，书话中带行踪者**等同游记**对待（第七辑）。

## 二、选目标准（三档）

1. **必收**：文史密度高、代表黄裳方法、具史料或文学双重价值、或为名篇定调之作。
   - 例（候选）：白门秋柳、金陵杂记（整组/精选）、老虎桥边看「知堂」、秦淮拾梦记、解放后看江南。
2. **可选**：题材重要但时评性强、或与必收篇重复地缘/主题，视全书容量取舍。
   - 例（候选）：司徒雷登夹着皮包走了以后、不再做花瓶（时代标本，注释后可入）。
3. **不宜收**：纯时政评论、与「行旅文史」主旨偏离、或重复度过高者。判例须在数据库 `editorial_note` 注明理由。

## 三、分辑逻辑（八辑）

按**主题—地缘—时间**三维交织分辑（详见 `outline/new_anthology_outline.md`）：
1. 蜀道与战时中国（西南行旅 / 抗战后方）
2. 美国兵与异国战争经验（战时中外军队接触现场）
3. 金陵旧梦（南京，**全书核心**）
4. 江南行旅（苏扬杭沪周边 / 水路 / 园林）
5. 北平与旧都余韵（旧城 / 琉璃厂 / 剧场 / 访书）
6. 山川、古迹与历史残影（不限地域，由名胜废墟入史）
7. 书肆、旧书与纸上行旅（带行踪的书话）
8. 人物途中（旅途所遇的作家、艺人、藏书家、戏曲人物）

**跨辑篇目处理**：一篇可属多辑者（如金陵的访书文），以**地缘完整性优先**入主辑，于他辑导读中「互见」提示，数据库 `editorial_note` 记录双栖关系，避免重复收录。

## 四、编排次序

- 辑内**先编年、后地点**：同辑按写作年代排，凸显作者眼光的成长与历史变迁。
- 「同地重访」诸篇**贴近编排**，形成对读。
- 每辑前置**导读**（见 `section_introductions.md`），点明该辑文史脉络与代表篇。

## 五、注释框架

每篇拟配三类注（繁简按出版形态定）：
1. **地理/史迹注**：地名今昔、建置沿革、所涉古迹。
2. **掌故/人物注**：所引史事、人物（如柳如是、马湘兰、周作人、司徒雷登）简注。
3. **版本/异文注**：初刊与结集本差异、可考的写作背景与时间。
- 注释只作背景说明，**不复制原文**；引用原句限短句并标页。

## 六、版权与诚信底线

- 全程**不大段复制受版权保护全文**；摘要为原创转述（≤200字）。
- 每条事实带 `confidence` 与 `source_reference`；**查不到即标待核，绝不臆造篇名/年份/出处**。
- 网络流传节选不作可靠底本，仅作线索；最终以**原书或《黄裳集》**核校。
- 正式出版前须取得版权方授权。

## 七、独特性诉求（本选本要做到的）

1. **结构创新**：以文史脉络而非书名/年代分辑，首次系统呈现「地点—史事—人物—书—戏」的交织。
2. **时间纵深**：用「同地重访」对读，呈现1940s—1980s眼光变迁。
3. **打通书旅与行旅**：把书话中的访书行踪正式纳入「行旅」范畴（第七辑）。
4. **学术配套**：编年篇目表、地点/主题多维标签、导读与三类注释，超越普通散文选。
5. **诚信标注**：全程「确定/待核/推测」透明化，可供研究者复核与续补。
