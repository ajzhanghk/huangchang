# 黄裳行旅散文集 · 重编项目（Huang Shang Travel Anthology）

一个面向「文学研究 + 专业出版 + 数字人文」的开放工作项目，目标是**重新搜集、整理、编排黄裳（1919–2012，原名容鼎昌）的散文与游记**，据此设计一部新的《黄裳行旅散文集》，使其选目、结构、注释与编排水准超越目前市面已有的同类选本。

> 本项目目前处于**框架搭建阶段**：已建立可扩展的数据结构、编辑原则、目录方案与研究工作流，并录入了一批已核 / 待核篇目。所有结论均标注「确定 / 待核 / 推测」。**未查证者一律标待考，不编造篇名、出处或年份。**

---

## 一、核心判断

黄裳的游记本质上不是普通旅游散文，而是**「地点触发的文史随笔」**：风景、旧迹、掌故、书籍、戏曲、人物与历史感交织在一起。全书结构据此建立——不按原书名或出版年代堆砌，而按**时间、地点、场景、主题、文史脉络**重新分门别类。

## 二、目标

1. 建立结构化、可持续补充的**篇目索引数据库**（地点 / 时间 / 场景 / 主题多维标签）。
2. 设计一部**八辑结构**的新选本目录（见 `outline/`）。
3. 形成可操作的**选编原则、导读框架、注释框架与出版方案**。
4. 输出专业总编辑级别的判断：必收 / 可选 / 不宜收 / 待核 / 选本独特性。

## 三、版权边界（重要）

- 黄裳作品**仍在版权保护期内**（作者2012年逝世）。本项目**不大段复制受保护全文**。
- 本仓库存储的是：**篇目索引、版本来源、内容摘要（≤200字，原创转述）、主题/地点标签、时间线、辑目结构、导读与注释框架、出版方案**。
- 必要引用**只保留短句**并记录出处；网络流传的节选不作为可靠底本。
- 数据库中每条记录均带 `copyright_status_note` 字段提示使用注意。

## 五、数据字段

每条篇目记录（`data/huangshang_essays.json` → `essays[]`）含：

| 字段 | 含义 |
|---|---|
| `id` | 内部稳定编号 |
| `title` | 篇名 |
| `original_collection` | 原收入书名 |
| `approximate_year` | 写作/首次发表时间，不可考则空 |
| `place` | 主要地点 |
| `region` | 蜀中/西南/金陵/江南/北平/上海/海外 等 |
| `scene_type` | 城市/江河/古迹/书肆/剧场/战时现场/旧宅/旅馆/寺观 等 |
| `themes` | 历史兴亡/掌故/书话/戏曲/人物/战时经验/城市记忆/江南文化/故都余韵 等 |
| `summary` | ≤200字原创摘要（非原文复制） |
| `editorial_note` | 为何值得收入、放在哪一辑 |
| `proposed_section` | 拟入辑号 1–8（0 表示附录/序跋） |
| `source_reference` | 版本或资料来源 |
| `copyright_status_note` | 版权与使用注意 |
| `confidence` | 确定 / 待核 / 推测 |

## 六、工作方法

1. **JSON 为唯一事实来源**，CSV 由 `build_csv.py` 派生，避免双份手工维护。
2. 新增/修改篇目 → 编辑 JSON → 运行 `python data/build_csv.py`；改完跑 `python data/validate.py` 校验。
3. 任何写入数据库的事实都要带 `confidence` 与 `source_reference`；查不到的标 `待核`，绝不臆造。
4. 以**《黄裳集》（山东人民出版社）**为主要底本与核对基准，辅以图书馆书目核定原始出版信息。
5. **生成 PDF 成稿**：`python data/build_pdf.py`（需 XeLaTeX，依赖 `texlive-xetex`/`ctex`/`xeCJK` 与中文字体；脚本用 AR PL 宋/楷 + 文泉驿黑体）。输出 `build/huangshang_anthology_plan.pdf`，含封面、目录、总序、选编原则、八辑目录与导读、**篇目总表（含原创摘要）**、行旅年表、资料来源、待核清单。

> **关于「收录全文」**：黄裳作品版权存续至 2062 年，本仓库及 `build_pdf.py` 生成的「编选方案 PDF」**不收录任何受版权保护的作品全文**，仅含篇目索引、原创内容摘要（≤200字）、版本来源与编辑框架。要点已写入 PDF 封面的「版权与编例说明」。正式出版前须取得版权方授权，并以原书核校全部文字。

6. **全本（个人阅读版）**：`python data/build_book.py` 由 `texts/<编号>.txt` 排印全本 PDF。**正文须由使用者据自藏原书自行录入**，仅供个人学习阅读。仓库不提供、不抓取任何正文；`texts/*.txt` 与全本 PDF 均已 `gitignore`，不会入库或外传。录入约定见 `texts/README.md`。

## 八、文艺评论（criticism/）

在篇目数据库与编选框架之上，新增一篇**原创文艺评论**《在风景里读历史——论黄裳的文史游记》（副标题「历史品味、文章趣味与风土人情」；作者 **ajzhanghk**，见 `criticism/huangshang_wenshi_youji_lun.md`），可作全书导论，亦可独立投稿发表。

- **核心论点**：黄裳痴迷的历史高度集中于**明清易代**，而他笔力最盛的金陵诸篇恰成于 1946–1949 另一个"易代之际"——**他读十七世纪，是为了照见自己亲历的二十世纪**。全文以这条"以古照今"的主轴，把历史品味、文章趣味、风土人情统摄为一个有内在动力的整体。
- **结构**：引子→历史的眼光（明清之际与道德审判）→怀古与见证（记者黄裳的"易代"现场）→文章趣味（周作人之闲与鲁迅之硬的调和）→风土人情（茶馆与"美人肝"以小见史）→三事一体（行旅·读史·访书）→时间纵深（同地重访）→结语。
- **翔实附录（全部已整理资料并入论文成稿）**：附录一·本文征引篇目举要；附录二·与本项目其他文献的关系；**附录三·黄裳行旅篇目总表（全六十六篇，含原创摘要）**；附录四·收录书目（书锚）与版本；附录五·黄裳行旅年表；附录六·待核清单与已知缺口。其中附录三–六由 `data/huangshang_essays.json` 与 `notes/timeline_draft.md` **经构建脚本自动汇编**，与《编选方案》PDF 同源同步，确保已搜集资料完整保留、不致散失。
- **成稿**：`python data/build_critique_pdf.py` → `build/huangshang_wenshi_youji_lun.pdf`（约 27 页，复用 `build_pdf.py` 的字体与 Markdown→LaTeX 引擎，0 缺字）。
- **版权诚信**：评论为原创，引述以公有领域古人成句与篇名为主，凡涉黄裳本人文字只取短句；史实凡未据原书坐实者以"据其文／疑／约"提示，严格标注以数据库为准。
