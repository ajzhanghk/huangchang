# 可持续研究工作流（Research Workflow）

本项目设计为**可长期、可多人、可续补**的整理工程。以下流程对应第四阶段要求。

---

## 0. 黄金规则

1. **JSON 是唯一事实来源**；改完 JSON 必跑 `python data/build_csv.py` 同步 CSV。
2. 每条写入都要带 `confidence`（确定/待核/推测）与 `source_reference`。
3. **查不到就标待核，绝不臆造**篇名、年份、出处。
4. 以**《黄裳集》（山东人民出版社）**为底本，原始出版信息以**图书馆书目/实物**核定。
5. 全程不大段复制受版权全文。

---

## 1. 如何继续查找篇目（Discovery）

**优先级从高到低：**
1. **原书逐篇过目**：按 `notes/source_bibliography.md` 第二、三节的书单，逐本录目（先金陵/西南/江南三大块）。
2. **图书馆 OPAC**：国图、上图、南图核版权页（出版社/年份/版次）。
3. **《黄裳集》总目**：以创作卷各册目录补齐单篇。
4. **二手线索**：豆瓣著者页/丛书页、Google Books、副刊评介——仅作线索，须回原书坐实。

**录入动作**：每发现一篇 → 在 `essays[]` 新增记录，填全字段，`confidence` 先按来源定，未坐实标 `待核`。

---

## 2. 如何标注地点和主题（Tagging）

- **place**：写最具体的地名（如「南京·鸡鸣寺」）。
- **region**：受控词表 —— 蜀中 / 西南 / 金陵 / 江南 / 北平 / 上海 / 海外 / 其他。
- **scene_type**：受控词表 —— 城市 / 江河 / 古迹 / 书肆 / 剧场 / 战时现场 / 旧宅 / 旅馆 / 寺观。
- **themes**：受控词表（可多选）—— 历史兴亡 / 掌故 / 书话 / 戏曲 / 人物 / 战时经验 / 城市记忆 / 江南文化 / 故都余韵 / 异国军队。
- 新增标签前先查词表，**避免近义词分裂**（如「怀古」统一记为「历史兴亡」）。
- 标注以**原文实际内容**为准；仅据篇名推断者，`confidence` 记 `推测` 并在 summary 注「据篇名推测」。

---

## 3. 如何做时间线（Timeline）

- 以 `approximate_year` 为轴；不可考留空，**不猜年份**。
- 一书内若有编年目录（如《金陵五记》分1942/1946/1947/1949/1979），照录其分层。
- 时间线产物：可由 JSON 脚本生成「黄裳行旅年表」（年份→地点→篇名），用于总序与附录。
- 区分**写作年**与**首刊年**，字段统一记「写作或首次发表时间」，差异大者在 `editorial_note` 说明。

---

## 4. 如何避免重复收录（Dedup）

- `id` 唯一；新增前用篇名+原书搜一遍现有 JSON。
- **同篇多书**（一文被多本收录）：只建**一条**记录，`original_collection` 记最早出处，其余版本写入 `source_reference`。
- **跨辑篇**：只入一个 `proposed_section`（地缘完整性优先），他辑用「互见」，在 `editorial_note` 写明，不另建记录。
- 定期跑去重检查（按 title 归并），见 §8 校验脚本建议。

---

## 5. 如何处理同一篇文章的不同版本（Variants）

- **同篇异文**（初刊本 vs 结集本，文字有改）：仍为一条记录，在 `editorial_note` 标「存在异文」，在 `source_reference` 并列各版本。
- 最终定本以《黄裳集》或作者生前末次结集为准，差异作「校记」附录。
- 标题异写（如「莫愁湖/奠愁湖」）以原书校正，错写记入校记。
- 凡涉异文的记录，`confidence` 不低于 `待核`，直到逐字校过。

---

## 6. 如何生成最终目录（Final Outline）

1. 篇目录入到一定覆盖度（六部主集 + 书话集大体齐全）。
2. 按 `proposed_section` 分组，辑内**先编年后地点**排序。
3. 复核每辑体量与平衡（核心辑最厚；弱辑补采或合并）。
4. 标注必收/可选，剔除不宜收（理由入 `editorial_note`）。
5. 由 JSON 生成目录草案，回填 `outline/new_anthology_outline.md`。
6. 同步更新各辑导读的「收文 N 篇、起讫年代、互见」。

---

## 7. 如何写导读、注释和总序（Apparatus）

- **导读**：每辑 200–400 字，点明文史脉络 + 代表篇 + 与他辑互见（见 `section_introductions.md`）。
- **注释**：三类——地理/史迹、掌故/人物、版本/异文（见 `editorial_principles.md` 第五节）。注释只作背景，不录原文。
- **总序**：见 `volume_preface_draft.md`；待全书定目后补总数与落定〔待核〕史实。
- 一切引用限短句并注页码；正式出版前取得版权授权。

---

## 8. 工具与校验（建议增量开发）

- `data/build_csv.py`：JSON→CSV（已具备）。
- 拟增 `data/validate.py`：检查 (a) `id` 唯一；(b) 受控词表合法性（region/scene_type/themes）；(c) `confidence` 取值合法；(d) 重复 title 提示。
- 拟增 `data/build_timeline.py`：由 JSON 输出年表 Markdown。
- 提交规范：每次录入/修订 → 跑 build_csv（及 validate）→ commit，commit message 说明新增/核定了哪些篇目与置信度变化。

---

## 9. 阶段路线图（建议）

1. **M1 金陵**：补齐《金陵五记》《白门秋柳》全篇目并逐条核定 → 第三辑定稿。
2. **M2 西南+美国兵**：录《锦帆集》《锦帆集外》《关于美国兵》→ 第一、二辑。
3. **M3 江南**：录《花步集》《晚春的行旅》→ 第四辑。
4. **M4 书旅+古迹+人物**：录书话/记人诸集 → 第五、六、七、八辑。
5. **M5 收束**：生成最终目录、年表、注释、总序定稿，整理版本校记。
