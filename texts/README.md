# texts/ — 自藏原书录入区（个人使用）

本目录用于存放**你本人据自藏原书录入的篇目正文**，供 `data/build_book.py`
排印成全本《黄裳行旅散文集》（个人阅读版）。

> **版权说明**：黄裳作品版权存续至 2062 年。本目录与本项目**不提供、不抓取**
> 任何受版权保护的正文；此处文字应由你从**自己拥有的纸书**录入（OCR 或手录），
> 仅供**个人学习阅读**，请勿复制、传播或公开发行。仓库默认不含任何正文文件。

## 怎么用

1. 按篇目编号建立文本文件：`texts/<编号>.txt`，例如 `texts/E-001.txt`（白门秋柳）、
   `texts/E-014.txt`（宝鸡——广元）。编号见 `data/huangshang_essays.json` 或
   `build/huangshang_anthology_plan.pdf` 的「篇目总表」。
2. 文件用 **UTF-8** 编码、纯文本。
3. 录入约定：
   - **空行分段**；段内的换行会被自动合并（OCR 硬换行无妨）。
   - 单独成行的 `## 小标题` 会排成篇内小标题（适合多节长文，如
     《金陵杂记》《印度小夜曲》《昆明杂记》）。
4. 运行 `python data/build_book.py`。
   - 已建文本文件的篇目 → 排入**正文全文**。
   - 未建的篇目 → 显示「正文待录入」占位 + 编辑摘要，便于分批补录。
5. 输出：`build/huangshang_anthology_full.pdf`。可反复补录、重跑。

## 示例 texts/E-001.txt

```
白门秋柳

〔在此粘贴你自藏《锦帆集》或《金陵五记》中本篇的文字。〕

第二段……

## 小标题（如本篇分节则用）

某一节文字……
```

## 进度查询

运行 `data/build_book.py` 时会打印 `Essays with supplied full text: N/66`，
即已录入篇数 / 总篇数（总篇数由脚本按数据库实时计算）。
